    Nueva plantilla

    El nombre es permanente: una vez creada la plantilla no se puede cambiar. Para usar otro nombre hay que eliminar la plantilla y crear una nueva.

    Es el nombre que verás al elegir la plantilla antes de un envío. No se puede repetir el de otra existente, ni el de una eliminada hasta pasados 30 días (política de Meta).

    No tienes áreas asignadas: pídele a un administrador que te asigne una para poder crear plantillas.
