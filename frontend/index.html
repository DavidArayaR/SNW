Sistema de Notificaciones WhatsApp (SNW)

Módulo web para gestionar y enviar notificaciones masivas de WhatsApp a pacientes de forma rápida, organizada y centralizada, directamente desde la plataforma de la empresa.

¿Cómo funciona el envío?

Tres pasos: selecciona los pacientes en la tabla, elige la plantilla del mensaje y presiona «Iniciar Envío». El sistema valida automáticamente cada número (formato internacional chileno +569XXXXXXXXX, corrigiendo errores comunes), descarta los inválidos sin interrumpir la cola, procesa el envío en segundo plano con un intervalo entre mensajes y registra el resultado de cada intento en el historial.

En entorno de desarrollo los envíos masivos se bloquean y solo salen mensajes hacia los números de prueba autorizados.

Ejecutar la versión completa en tu equipo

Esta página es una demostración estática: los datos son de ejemplo y los cambios no persisten en un servidor. Para usar el sistema real necesitas Python, MySQL (XAMPP) y ejecutar:

pip install -r requirements.txt
cp .env.example .env   # y completar credenciales
python backend/main.py

Luego abre http://localhost:8000. Las instrucciones completas están en el README del repositorio.

⚠️ En esta demo los botones de guardado y envío simulan el comportamiento; ningún mensaje real sale por WhatsApp.
